# EZHub 官网 V1 规格

## 品牌与功能范围

EZHub 是个人独立软件创作品牌，核心文案为“让想法成为好用的软件。”品牌标识采用 EZHub，中文母品牌名暂缓。官网用于介绍品牌并展示 eNote（易笔记）、BuildingStore 等独立软件。产品描述、界面截图与链接以确认可公开的内容为准。

V1 为中文优先的纯静态网站，保留以后扩展其他语言的空间。首版范围为品牌介绍与产品展示，数据库、登录、CMS 和商业交易不在 V1 范围内。

## 页面结构与视觉方向

- 首页包含导航、品牌首屏、产品展示和页脚。首屏采用品牌文案与软件界面概念视觉。
- 后续实现产品页与关于页。具体路由和公开内容随对应页面确认。
- 采用现代极简风格，以明亮主题为主，蓝色搭配少量紫色渐变，使用留白、圆角卡片和轻量动效。产品展示采用桌面双列与移动端单列。
- 原型中的产品界面与图标属于设计示意。正式内容应准确反映产品现状。

## 当前实现

Phase 1B 首页包含品牌名、核心文案、中文文档元数据与基础响应式样式，用于本地验证 Astro 静态输出。正式视觉原型、导航和产品展示尚未实现，正式页面需另行完成视觉验收。
