# EZHub 官网 V1 规格

## 品牌与定位

EZHub 是个人独立软件创作品牌。核心文案为“让想法成为好用的软件。”品牌原则为“简单、实用、持续创造”。品牌标识使用 EZHub，中文母品牌名尚未确定。官网 V1 中文优先，介绍品牌并展示 eNote（易笔记）与 BuildingStore。

## 页面范围

以下为 V1 目标。Astro 已实现首页 `/`、产品中心及 eNote 和 BuildingStore 的产品详情页。各页共用响应式导航和页脚，产品详情展示公开定位、研发状态与设计方向。关于页和自定义 404 尚未实现。

| 页面 | 目标 |
| --- | --- |
| `/` | 提供品牌首屏、主导航、主要产品入口与页脚 |
| `/products/` | 汇集产品简介与详情入口 |
| `/products/enote/` | 展示 eNote 的定位、已确认的能力和可用入口 |
| `/products/buildingstore/` | 展示 BuildingStore 的定位、已确认的能力和可用入口 |
| `/about/` | 介绍 EZHub 及品牌理念 |
| 自定义 404 | 说明页面未找到，并提供返回首页或产品索引的入口 |

`/journal/` 在具备真实、可公开发布的内容时启用。多语言、数据库、账号、CMS 与支付超出 V1 范围。

## 内容与视觉

产品内容至少包含名称、路由标识、简述和经确认的当前状态。能力说明、截图及下载或外部链接按实际可公开的版本和来源提供。以项目维护者确认的公开资料或可复核版本为依据。产品首版处于研发阶段时标注“研发中”。公开的功能说明区分“已实现”和“规划中”，未知发布状态留待确认。下载入口须与真实发布状态一致，仅在对应版本已公开提供时展示。概念视觉明确标注为示意，产品截图须对应真实界面。

采用现代极简、明亮主题，以蓝色为主，辅以克制的紫色渐变。使用充足留白和圆角产品展示卡片，按视口调整布局。精确视觉对照以页面开发时取得并确认的原型为输入。

## V1 验收

- 核对所有目标页面和导航链接，验证自定义 404 的呈现、返回入口及发布环境中的 HTTP 状态。
- 在 375px、768px、1280px 代表性视口检查页面结构、导航、排版、媒体和横向溢出。检查语义化 HTML、标题层级、键盘导航及可见焦点，并为有意义的图片提供替代文本。
- 为公开页面设置准确的标题、描述及适用的分享元数据。验证 Sitemap、站内链接和索引配置，确保应公开的页面可被发现。
- 检查首屏资源、字体加载和布局稳定性。图片使用适合显示尺寸的资源，非首屏图片按需延迟加载。动效遵循 `prefers-reduced-motion`。
- 发布时验证静态产物、目标环境路由、HTTPS、自定义域名和回滚方式，并记录可恢复的发布版本。发布和权限变更见[开发工作流](WORKFLOW.md)。

## 技术边界

采用 Astro 与 TypeScript 生成静态站点。GitHub Pages 与自定义域名 `ezhub.cn` 是后续发布目标。内容结构、资源组织和具体部署方式在对应实施任务中根据实际页面与平台约束确定。内容模型可先由静态页面或共享数据承载，出现实际维护需求时再评估更复杂的方案。品牌、公开页面范围或发布形态变化时，先确认并更新本规格。
